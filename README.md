# Tilewright / Lantern Trails

[![Tilewright CI](https://github.com/YouKnowJP/Tilewright/actions/workflows/pages.yml/badge.svg)](https://github.com/YouKnowJP/Tilewright/actions/workflows/pages.yml)

**[Play Lantern Trails](https://youknowjp.github.io/Tilewright/)** · [Report a bug](https://github.com/YouKnowJP/Tilewright/issues) · [Documentation](docs/README.md)

Make a little world, then go on an adventure. Tilewright combines an original
turn-based puzzle game with a terrain editor and Adventure Workshop. Players
need only the website link: no account, installation, GitHub clone, or terminal.

**Free to play. New protected work is not licensed for commercial copies.**
Paid downloads, ad-supported copies, subscription rehosting and asset resale
need the owner's written permission. Links to the official game, fan videos
(including creator revenue), and noncommercial world sharing are welcome.
**The game through v0.30.1 remains MIT licensed, including commercial reuse;**
these restrictions apply only to new protected material. Read the
[permissions guide](docs/RIGHTS.md) and [full license](LICENSE).

## Play, explore, and create

- 24 campaign missions, eight Guild jobs, daily trails and branching expeditions.
- Twenty-three featured Storybooks, including 107 unique original book levels, plus Puzzle Lab journeys.
- 87 featured worlds, twelve Lab rooms, village commissions, and optional challenges.
- Create puzzles, write dialogue, rotate rooms, coordinate two travelers, and share adventure files, codes, links, or Storybooks.
- Character customization, separate save journeys, Undo, exact Continue, training lessons, and portable backups.
- Phone/tablet/desktop layouts, pad/swipe/tap/keyboard/controller choices, fullscreen with expanded fallback, large text, high contrast, and color-independent map cues.

Choose **Play Pip & Sprout** on the main menu. Adventure Home offers seventy-six story chapters, a suggested next road, saved setups, searchable mechanic/progress filters, and your saved collections. Open the creator or collection builder from **Create & share**. **How to play → Learn the cards with Pip** opens the classic lessons. The older Workshop and Trailhouse entrances remain available. [Workshop guide](docs/PIP_WORKSHOP.md).

Use **Garden, Cards, Tools and Hints** to navigate the workbench. Test/Undo/playback sit beside the garden; briefing and advanced choices stay folded. Duo hints progress from a clue to an experiment and finally an optional worked route. Three tiny practice gardens teach handoffs, bell timing and passport checks without changing your adventure. Saved collections resume their test position with Undo; ordinary story continuation restores saved cards and parts. Dress Pip, display three favorite inventions, and share projects, collection files/codes/links or illustrated posters. Existing ordinary Pip adventures retain **Advance to next event**, numbered rehearsals and the Community shelf.

With the garden focused, **Space/Enter** steps a test, **R** runs/pauses and **Z** undoes. Inspect with arrows or your saved WASD/IJKL layout; bench placement still uses Space/Enter. Practice supports stepping and Undo too. Escape pauses a running test before leaving, and playback pauses when the window or page is away. Menus and confirmations own controller input, so Undo cannot edit the adventure behind them.

**Pip & Sprout · story & creator** adds six duo story missions and an open garden editor. Paint roads, move both companions, write dialogue and combine recipes, tubes, bridges, memories and signal stamps. Configure or capture reusable blueprints, keep twelve adventures and twelve pieces per journey, and send friends a playable project link. All six opening chapters include optional worked examples. The **Night Post** collection adds six harder chapters with linked parcel lockers, cargo compasses, two-way depot trades and limited-parts repairs. Mirror and arrange blueprint copies, preview their footprint, and revise named pieces without changing parts already placed in adventures. **Dawn Workshop** adds four mastery repairs, bringing the duo story to sixteen chapters. Rehearse routes with inspectable event frames, or reshape your own garden with rotation, mirroring, protected resizing and area brushes. **The Canopy Fair** adds four original tower, handoff and bridge repairs for twenty duo chapters in total. Reconnect blueprint tubes and lockers independently of recipes, suggest unused link numbers, or find a valid space before placing a piece. A waiting-bell gate and corner atelier bring the reusable template library to ten.

**Canopy After Hours** adds four mastery variations for twenty-four duo chapters. In **Share & feedback → Adventure collections**, arrange up to six story/player adventures, edit chapter notes and share one file, PC1 code or hosted play link. Friends get a chapter menu, fresh-route challenges and optional creator replays. **The Clocktower Ledger** adds four original timing challenges, bringing the duo story to twenty-eight chapters. Keep eight collections per journey, duplicate chapters, and update or copy assemblies. Assemblies, chapter setups, paused test positions and verified clears save automatically between visits. Resume with Undo history, restart a collection or download a full journey backup; shared PC1 collections contain authored chapters rather than personal progress. **Star Atlas** continues with four harder Clocktower variations for thirty-two duo chapters. Combine chapters from different saved collections, reverse or undo arrangements, remix chapter gardens and replace individual maps. Download an illustrated collection poster alongside the playable file or code; advanced tools stay folded. **Lantern Workshop** adds four switch adventures for thirty-six duo chapters. A lantern remembers power after a courier leaves, opening numbered bridges and routing signal stamps on the next tick. Create switch-off homecomings with two new blueprints, build verified variant sets, or download a single chapter as its own collection.

**The Bellkeeper** adds four timed-power challenges for forty duo chapters. Configure two bell blueprints, coordinate one to six powered ticks, and design silent-bell homecomings. In the folded **Curator tray**, choose chapters from assemblies or saved collections, copy them as one undoable batch, or share a selected collection, link or poster with original maker credits.

**The Sealkeepers** adds four passport missions for forty-four duo chapters. Parcel seals inspect cargo, courier badges and selected entry directions; two reusable pieces help build outward and return lanes. Add optional tick/part goals, set a verified creator par and share bonus editions alongside ordinary collections. Earned ribbons retain their best answer through later retries.

**The Rainwrights** adds four original expert/master chapters for forty-eight duo adventures. Coordinate three handoffs, a covered locker depot, a one-beat return crossing and a six-letter lantern council. In **Shape your garden → Sketch a road**, preview across-first, down-first or staircase paths before applying one undoable edit. Water protects companions and stations. Save road-only stencils to the blueprint shelf, then turn, mirror, place or download them for a friend. Previewing and stencil sharing keep adventure progress separate.

**The Tidekeepers** adds four harder rhythmic adventures for fifty-two duo chapters. Automatic **T** beacons cycle through open and closed beats; tune their cycle and phase, inspect the next eight turns, and coordinate bridges and dispatch signs. New blueprints support staggered copies and optional retiming of every beacon in an imported piece. Shared creations keep maker credits; saved collection tests restore their exact phase and Undo history.

**The Balancekeepers** adds four expert/master repairs for fifty-six duo chapters. Cargo scales **V** check a courier’s badge and carried parcel at turn start: hold a loaded crossing, unload for an empty-hand return, or power a dispatch sign for a friend. Configure two reusable scale blueprints. Folded **Wire power circuits** tools reconnect power without changing recipes, parcel requirements or tube/locker links. Capture, save and share pieces with maker credits; exact collection continuation retains one-turn crossings and Undo.

**The Echo Post** adds four expert/master repairs for sixty duo chapters. Echo stamps **J** learn a friend’s route from the start of the turn, then copy, turn, mirror or reverse its cards. Plan first replies, a backward letter, a four-delivery compass crossing and a locker council. Two new echo blueprints bring remote instructions into your creations. Folded **Rewrite route cards** tools edit one station and bank at a time, with swaps, card cycling, restoration and readable final instructions. Keep, capture and share pieces; saved collections preserve exact echo turns and Undo.

**The Mixing House** adds four ingredient adventures for sixty-four duo chapters. A **mixing bowl Y** keeps the first ingredient until a courier adds the other, then gives the blend to that courier. Plan a shared crossing, four-lap recipes, borrowed ingredients through lockers and a six-letter kitchen council. Two mixing blueprints support different recipes and cargo forks. Folded **Remix parcel colours** tools swap ingredients, windows and cargo checks while power circuits, tube pairs and locker links keep their numbers. Combine recipe remixes with rewritten cards, capture/share pieces and Undo a whole placement. Saved collection tests retain partly filled bowls and complete Undo history.

**The Kilnkeepers** adds four powered-recipe adventures for sixty-eight duo chapters. **Recipe kilns I** fire the same input into different Quiet/Powered outputs, reading power before either courier acts. Coordinate clock-fired letters, windows that warm the next recipe, an eight-letter hourglass crossing and a mixing-bowl council that finishes with both lanterns off. Two kiln blueprints bring timed or remembered heat to your creations. Folded **Rewrite station recipes** tools revise individual presses, bowls and kilns, copy recipes to matching machines, trade kiln outputs or restore originals. Combine formulas with card banks, parcel palettes, power wiring, reflection and capture; saved sources and garden history remain separate until you keep or place the preview.

**The Weavekeepers** adds four harder circuit adventures for seventy-two duo chapters. **Weave relays W** combine two source numbers with Both, Either, Exactly one or Neither, then power a separate output number. Coordinate overlapping tides, unequal lantern rhythms, quiet recipe intervals and a six-letter homecoming. Two reusable blueprints and folded **Compose relay circuits** tools offer individual source/rule editing, truth tables, bulk rule copying, number cycling and restoration. Combine them with route cards, capture, sharing and whole-piece power wiring. Saved collections restore the exact turn and Undo history.

**The Meeting House** brings the story to **96 duo chapters**. Four new missions use matching Rendezvous Posts to coordinate couriers through rails, a delayed bridge pulse, and four laps with two meetings each. The Workshop includes **Meeting lanes**, **Staggered lanes**, a timing preview, and separate links for each blueprint copy.

**The Switchyard** brings the story to **92 duo chapters**. Four new missions use Switch Rails to carry a courier between routes while keeping its next card ready. The puzzles link rails to footfall pulses, a delivered letter, a delayed drum and a lantern that changes the branch each lap. The Workshop includes **Sidecar corner**, **Two-way switch** and a ride preview for custom blueprints.

**The Footfall Archive** brings the story to **88 duo chapters**. Four new missions count courier arrivals to time crossings, handoffs, alternating kilns, and a final delivery of four blended parcels. **Footfall Counters O** can count either courier or just one and send power after a chosen number of arrivals. In the Workshop, start with **A crossing on two steps** or **The walking kiln**, then open **Tune footfall counters** to set starting marks and preview the rhythm.

**The Windward Post** brings the story to **84 duo chapters**. Four new missions teach walking turns, timed handoffs, changing kiln recipes, and reverse-order routes. **Wind Vanes F** change cards on entry and keep the next card position. In the creator, **Shape turns & mirrors** edits vanes and prisms, previews any three example cards, and composes with the existing rotation, capture and sharing tools. Start with **A walking corner** or **A mirrored stroll**.

**The Wayside Keepers** adds four original pacing adventures for **eighty duo chapters**. **Rest Stones R** hold one courier’s next card and parcel for one to six following turns while the other friend and every clock keep moving. Repair one-beat crossings, keep three rendezvous, retime the observatory’s recipes and finish a long lantern walk. Two new blueprints and folded **Compose station timing** tools support individual/bulk pauses, bounded longer/shorter edits and staggered rests. Rehearsals filter resting events; the new compact HUD keeps detailed courier cards and machines folded. Saved pauses, Undo, creator pieces and shared collections retain their timing.

**The Drumkeepers** adds four harder timing adventures for seventy-six duo chapters. **Memory Drums D** record a power beat and repeat it one to six turns later. Build delayed crossings, carry one-beat bell signals across time, glaze letters using remembered heat and bring both friends home with every drum quiet. Two new blueprints and folded **Compose station timing** tools let you edit one clock, bell or drum, copy timing, shift/stagger clocks and inspect sixteen conditional beats. Combine them with route cards, circuit rules, power wiring, capture and sharing. Pending drum memories survive saved collection tests, Undo and backups.

The Clockwork Gardens Storybook still offers six longer adventures with remembered routes, returning parcels, a shared ferry and independent flip stamps. Existing worlds and saves keep their identities.

## Play and save

Progress stays in this browser. The old `/Personal-Project/` address and new
`/Tilewright/` address use the same `youknowjp.github.io` origin, and the game
keeps its existing `tilewright.*` save keys. Existing saves can therefore be
read at the new address in the same browser. Download a backup before clearing
data or moving to another browser/device/origin. World play links and the Home
Screen launcher now use the new location. No migration uploads player saves.

## Local development

Requires Node.js 22+. From this repository's root:

```sh
git clone https://github.com/YouKnowJP/Tilewright.git
cd Tilewright
npm ci --ignore-scripts
npm start
```

Open http://127.0.0.1:4174/. Serving the development game itself needs no runtime
packages; the locked development tools support browser testing. `file://` does
not support the module setup.

```sh
npm run verify
npm run check:public
npm run check:repository
npm run test:browser:smoke
```

Install the test browser once with
`npx playwright install --with-deps --only-shell chromium`. See [test tooling](scripts/README.md).

## Publishing

Push to `main` to run the Node/OS matrix and built-game Chromium checks, then
publish the tested `dist/` directly through this repository's GitHub Pages
workflow. No second hosting repository or deployment key is needed. Failed
checks prevent publishing. See [deployment](docs/HOSTING.md).

| Path | Contents |
| --- | --- |
| `src/`, `index.html`, `*.css`, `icons/` | Editable game and editor source/assets |
| `tests/` | Deterministic rules, saving, packaging, and route regression tests |
| `scripts/` | Build, artifact validation, browser checks, and route tools |
| `docs/` | Player/developer guides, migration, research, and reviewed QA |
| `.github/` | CI/Pages, ownership routing, and issue templates |
| `dist/` | Generated playable site; ignored by Git |
