Your privacy

The game stores saves, settings, worlds and local opponent-learning counters in this browser. It has no game account, analytics SDK, remote AI service or cloud-save backend. Exporting a backup keeps it on your device; sharing a file/code/link intentionally gives its included world data to the recipient.

GitHub Pages receives normal website requests under GitHub’s privacy policy. See the privacy details. The old and new GitHub Pages paths share an origin and unchanged save keys, so previous saves remain available in the same browser. Back up before clearing site data or changing browsers/devices.
